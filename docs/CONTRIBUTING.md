# Contributing to Ovrino

Thanks for helping improve Ovrino.

## Before changing code

1. Read the project README.
2. Check the roadmap for the relevant phase.
3. Keep the change focused.

## Development

```bash
npm install
npm start
```

## Pull requests

A useful PR should explain:

- What changed
- Why it changed
- How it was tested
- Any limitations or follow-up work

Avoid bundling unrelated refactors into feature changes.

## Commits

Prefer short, descriptive commit messages such as:

```text
feat: add voice picker
fix: handle failed speech generation
style: improve audio player layout
docs: update voice system
```
