# Creator Mode

Creator Mode is designed for narration and short-form voiceover workflows.

## Current workflow

1. Paste a longer script.
2. Ovrino splits it into sentence-aware takes.
3. Select an individual take to rehearse it.
4. Generate the current take or generate the full sequence.
5. Generated takes are also recorded in local history.

The splitter keeps takes below a practical length target while preferring sentence boundaries.

## Current limitation

The device TTS provider does not return reusable audio files. Creator Mode therefore focuses on repeatable generation and take organization now; export of actual audio files will be completed when the production provider is integrated.
